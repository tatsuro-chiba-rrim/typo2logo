# Typo2Logo

フォントの外形を「湖岸線」と見立て、内側と外側へ再帰的な平行線を描いてロゴを生成するブラウザアプリです。

## 特徴

- 文字輪郭に沿った再帰バッファー風の水際線
- 内側／外側／内外の輪郭線を切り替え
- 距離に応じた滑らかな同系色グラデーション
- 青い文字面、淡い青の内側線、オレンジの外側線、濃色の文字境界を個別指定
- 「外側のみ」でも文字内部の色を独立指定
- 文字間隔、線間隔、線幅を調整
- Waterline、Fill + Waterline、Distance field の3モード
- TTF / OTF / WOFF / WOFF2 のローカルフォント読込
- 透過背景とPNG保存
- サーバー不要の単一HTMLファイル

初期パレットは、文字面 `#339CFF`、内側線 `#95C2EC`、外側線 `#F3883B`、文字境界 `#2C2927` です。輪郭線は色を交互に切り替えず、再帰段階に沿って連続的に補間します。

## 使い方

1. `index.html` をブラウザで開きます。
2. 文字とフォントを選び、必要に応じて文字間隔、線、色を調整します。
3. **RUN** で再生成し、**SAVE PNG** で保存します。

入力した文字とローカルフォントはブラウザ内だけで処理され、外部へ送信されません。

## 実装

Canvas 2D上で文字マスクの距離変換を行い、指定した再帰距離ごとの差分を連続した輪郭線として描画しています。線分を個別に接続しないため、縫合線が出にくい構成です。
