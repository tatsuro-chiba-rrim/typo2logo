# Typo2Logo

文字または画像の外形を「湖岸線」と見立て、内側と外側へ再帰的な平行線を描いてロゴを生成するブラウザアプリです。

## 特徴

- 文字輪郭に沿った再帰バッファー風の水際線
- 内側／外側／内外の輪郭線を切り替え
- 距離に応じた滑らかな同系色グラデーション
- 青い文字面、淡い青の内側線、オレンジの外側線、濃色の文字境界を個別指定
- 「外側のみ」でも文字内部の色を独立指定
- 文字間隔、線間隔、線幅を調整
- Waterline、Fill + Waterline、Distance field の3モード
- TTF / OTF / WOFF / WOFF2 のローカルフォント読込
- PNG / JPEG / WebP / SVG などの画像入力
- 画像の表示サイズと二値化スレッショルドを調整
- 透明画像はアルファ、通常画像は明るさからマスクを自動生成
- 明暗マスクの反転に対応
- 透過背景とPNG保存
- サーバー不要の単一HTMLファイル
- テキスト・画像の両方に使える9種類の外観プリセット（ネオン、オーロラ、ゴールド、シルバー、蛍光印刷、ポップ発光、クール＆ウォーム、水彩）
- 発光、にじみ、明るさを調整し、同じ輪郭で9種類の見本を比較
- 9種類または調整中のプリセットをJSONで保存・再読み込み

初期表示は「千葉達朗」のネオンです。**従来の配色（手動調整）** を選べば、文字面・内側線・外側線・文字境界の4色を個別に調整できます。プリセットの切替時に、線幅・線間隔・内外範囲を維持する設定もあります。金属光沢・蛍光色・水彩は、RGBの色と画像処理による見た目の表現です。

## 使い方

1. `index.html` をブラウザで開きます。
2. 左上の **入力方法** で **テキスト ＋ フォント** または **画像ファイル** を選びます。
3. 文字の場合は文字とフォントを、画像の場合はファイル、サイズ、スレッショルドを調整します。
4. プリセット選択欄または見本をクリックし、発光・にじみ・明るさを調整します。文字入力は自動で再描画されます。
5. **RUN** で再生成し、**SAVE PNG** で保存します。PNG名にはプリセット名と日時を含めます。
6. **現在のJSON** は調整中の色・効果・輪郭設定を、**9種類のJSON** は初期プリセット全体を保存します。**JSON読込** で再利用できます。

入力した文字、ローカルフォント、画像はブラウザ内だけで処理され、外部へ送信されません。

## 実装

Canvas 2D上で文字または画像の二値マスクを作り、距離変換から再帰距離を求めています。画像は2倍解像度のマスクから輪郭を一度だけ連続パスとして抽出し、文字と同じ「太いストロークから細いストロークを消去する」再帰バッファー差分で線を生成して、最終サイズへ高品質に縮小します。再帰線同士を結ぶ線分は追加しないため、画像モードでも縫合線のない滑らかな平行線になります。

9種類の外観はHTML内の `application/json` に定義しています。画像の連続パス化と文字・画像のストローク差分エンジンはそのまま使い、輪郭生成後の色付け・光彩・反射帯・紙の粒子を追加します。JSONの `schemaVersion: 2` はこの統合版の輪郭設定に対応します。

## 進化・選抜モード

ヘッダーの **進化・選抜モード** ボタンで開始します。通常の文字・画像編集と9種類のプリセットも引き続き利用できます。`index.html`だけでも動作し、外部APIや生成AIの契約は不要です。

1. ロゴにする文字、予選の回数、対戦形式を設定します。
2. 100案を20案ずつ閲覧し、10案を選びます。カードを押すと拡大・PNG保存・参考事例・親の情報を確認できます。
3. 予選を指定回数繰り返してから、残した案を一対一で比較します。
4. 上位10案を親にして、交配と突然変異で次世代を生成します。最初の100案には親10案を変更せずに保存し、90案を交配します。以後の予選は100案すべて新しい交配案です。

### 対戦と評価

- スイス式：5ラウンド。成績の近い案を優先し、同じ組合せを避けて対戦します。30案なら75対戦です。組合せ探索に上限があり、成立しない場合には未対戦を優先する順次割当へ切り替えます。
- 総当たり：全組合せを1度ずつ比較します。30案なら435対戦です。
- 勝ち1点、引き分け0.5点。同点では対戦相手の合計得点、勝数、予選から残した順で順位を決めます。
- 最後の投票は戻せます。評価は利用者の投票によるもので、AIによる美的採点ではありません。

### 遺伝する特徴

書体系統、太さ、字幅、字間、傾斜、文字回転、水平・アーチ・波・交互・2段の配置、塗り・輪郭・インライン・ステンシル・エコー・立体・ネオン・ストライプ、配色、輪郭の本数・間隔・太さ。数値は親の値または平均、カテゴリは親のいずれかから継承し、設定した確率で変異します。初期生成と組合せはシードから再現できます。見た目は利用端末のフォント環境にも依存します。

### 保存と通常編集への転送

- この端末のブラウザに自動保存します。保存できない場合は画面に表示します。
- 「途中経過をJSON保存」で文字、候補、選択、投票、親、過去世代の上位案を保存できます。「再開・JSON読込」で復元します。
- JSON読込は形式・数値・候補IDを検証し、対戦を再計算します。
- 個別PNGと上位10案の一覧PNGを書き出せます。
- 「形を通常編集へ」は候補の文字形を透明背景の画像マスクにし、従来の輪郭・配色編集に渡します。色効果は通常編集側の設定になります。

### 100件の研究用参考事例

`evolution-references.json`には、Pentagramの公開制作事例からワードマーク・ロゴタイプ・モノグラムに言及する100例を収録しています。同じデータをHTMLにも埋め込み、各事例の制作元へのリンクを表示します。これは研究用の選定で、世界のロゴの品質ランキングではありません。分類は解説文から抽出した造形上の研究視点です。

候補は参考画像のトレースや変形ではなく、その構成原理を手掛かりに入力文字とパラメータから描きます。ロゴの画像は配布していません。会話で提示したImageGenの途中見本は方向性を探るための別の画像で、このブラウザ内生成エンジンの出力ではありません。

## 銅色・明朝輪郭（採用案③）

9番目のプリセットです。アイボリーの背景、深い銅色の芯、細い銅色・クリーム色の多重輪郭を再現します。文字と画像の両方に適用できます。

- 「銅色の推奨設定」：入力文字を保持して明朝体・標準の輪郭設定を適用します。
- 「採用案の字形を使う」：選択画像からImageGenで作った「千葉達朗」固定の透明シルエットを読み込みます。画像をピクセル単位で再現する機能ではありません。
- 「進化・選抜モード」の新しい初期候補にも銅色輪郭の案を加えました。以前の保存JSONも読み込めます。
- `Typo2Logo_9_presets.json` に全9種類の設定を収録。採用案の字形はHTMLに埋め込んでいるため、HTML単体でも利用できます。

字形素材は、ユーザー指定の採用画像を入力に、黒一色・透明背景・4文字の形状保持・装飾線除去を指定して組み込みImageGenで作成しました。任意の文字への適用は、選択フォントに同系統の色・輪郭効果を施します。
