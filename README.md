# Typo2Logo

文字または画像の外形を「湖岸線」と見立て、内側と外側へ再帰的な平行線を描いてロゴを生成するブラウザアプリです。

## 特徴

- 文字輪郭に沿った再帰バッファー風の水際線
- 内側／外側／内外の輪郭線を切り替え
- 距離に応じた滑らかな同系色グラデーション
- 青い文字面、淡い青の内側線、オレンジの外側線、濃色の文字境界を個別指定
- 「外側のみ」でも文字内部の色を独立指定
- 文字間隔、線間隔、線幅を調整
- Waterline、Fill + Waterline、Distance field の3モード
- TTF / OTF / WOFF / WOFF2 のローカルフォント読込
- PNG / JPEG / WebP / SVG などの画像入力
- 画像の表示サイズと二値化スレッショルドを調整
- 透明画像はアルファ、通常画像は明るさからマスクを自動生成
- 明暗マスクの反転に対応
- 透過背景とPNG保存
- サーバー不要の単一HTMLファイル
- テキスト・画像の両方に使える8種類の外観プリセット（ネオン、オーロラ、ゴールド、シルバー、蛍光印刷、ポップ発光、クール＆ウォーム、水彩）
- 発光、にじみ、明るさを調整し、同じ輪郭で8種類の見本を比較
- 8種類または調整中のプリセットをJSONで保存・再読み込み

初期表示は「千葉達朗」のネオンです。**従来の配色（手動調整）** を選べば、文字面・内側線・外側線・文字境界の4色を個別に調整できます。プリセットの切替時に、線幅・線間隔・内外範囲を維持する設定もあります。金属光沢・蛍光色・水彩は、RGBの色と画像処理による見た目の表現です。

## 使い方

1. `index.html` をブラウザで開きます。
2. 左上の **入力方法** で **テキスト ＋ フォント** または **画像ファイル** を選びます。
3. 文字の場合は文字とフォントを、画像の場合はファイル、サイズ、スレッショルドを調整します。
4. プリセット選択欄または見本をクリックし、発光・にじみ・明るさを調整します。文字入力は自動で再描画されます。
5. **RUN** で再生成し、**SAVE PNG** で保存します。PNG名にはプリセット名と日時を含めます。
6. **現在のJSON** は調整中の色・効果・輪郭設定を、**8種類のJSON** は初期プリセット全体を保存します。**JSON読込** で再利用できます。

入力した文字、ローカルフォント、画像はブラウザ内だけで処理され、外部へ送信されません。

## 実装

Canvas 2D上で文字または画像の二値マスクを作り、距離変換から再帰距離を求めています。画像は2倍解像度のマスクから輪郭を一度だけ連続パスとして抽出し、文字と同じ「太いストロークから細いストロークを消去する」再帰バッファー差分で線を生成して、最終サイズへ高品質に縮小します。再帰線同士を結ぶ線分は追加しないため、画像モードでも縫合線のない滑らかな平行線になります。

8種類の外観はHTML内の `application/json` に定義しています。画像の連続パス化と文字・画像のストローク差分エンジンはそのまま使い、輪郭生成後の色付け・光彩・反射帯・紙の粒子を追加します。JSONの `schemaVersion: 2` はこの統合版の輪郭設定に対応します。
